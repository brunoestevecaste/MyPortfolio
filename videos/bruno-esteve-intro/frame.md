# Design specification · v3

- Canvas: #F9F4F4, exactly the portfolio canvas. Accent: #C1282E. Ink: #121416.
- Typeface: shipped Bricolage Grotesque; display 800, secondary copy 500. SVG labels use outlined glyphs from the same font.
- 1080 × 1350, 30 fps, 19.5 seconds. Safe horizontal inset 108 px.
- Opening: value and name readable together from frame zero. No typewriter, scramble, cursor or early domain CTA.
- Projects: three distinct simplified interfaces. Titles and value statements remain outside the interface. Each has 2.667 seconds and a fixed 864 × 600 visual window at (108,470).
- AEPD: observed traffic and hourly forecast, fictional series; staged prediction reveal.
- NextPlan: personalized event plus location; button changes from Guardar plan to Plan guardado when pressed.
- Alina: eight demo skills and an explainable 80% match, followed by a verified letter and interview preparation.
- Every interface is identified as a recreation with illustrative data. No operational performance claims.
- Motion grammar: continuous symbol-to-panel transform, opaque slides between projects, semantic result reveals, then seeded particles into the original logo.
- Particle scene begins with the exact last project layout; source image and particles overlap briefly so the interface does not disappear on a cut.
- Closing 14–19.5 s: carry the full formed logo into a shrink/upward move; reveal NOS VEMOS EN and a red brunoesteve.com button. Cursor arrives, presses at 16.45 s, releases with a small spring and leaves. The button collapses into ENJOY ;) at 17.46 s; final lockup holds from 17.94 s until the end. No Explora mis proyectos page.
- Seven sound cues. Each belongs to a visible travel, save state, particle dissolve, logo landing or domain lock. Frozen local assets, no music or voiceover.
