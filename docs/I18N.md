# Idiomas del portfolio

El menú de la página principal alterna español e inglés mediante una Server Action.
En las páginas de proyecto, el control derecho es el enlace de vuelta. Mantienen
el idioma seleccionado en la página principal, sin menú ni selector de idioma. La cookie
`portfolio-language` conserva la elección durante un año. Sin una elección válida,
el sitio se muestra en español. Next.js devuelve los componentes actualizados en
la misma petición; se conservan la URL y el estado de los controles interactivos.

El idioma se resuelve en el servidor antes de generar el HTML, los metadatos y
`html.lang`. Esta preferencia por cookie implica renderizado por petición. El
contenido editorial sigue en Server Components y no hay servicios de traducción,
peticiones de traducción ni dependencias adicionales durante el uso del sitio.

- `src/data/i18n/en.json`: traducciones exclusivas del servidor.
- `src/data/i18n/en-client.json`: traducciones utilizadas por componentes
  interactivos; también están disponibles en el servidor. Se envían al navegador
  solamente cuando el idioma es inglés. No duplicar claves entre los archivos.
- `getTranslations()`: traducción en componentes de servidor.
- `useTranslations()`: traducción y locale en componentes interactivos.

El texto original español es la clave. Para contenido variable, usar
`t("Tramo {0}", [segment])`. Traducir los textos visibles y las etiquetas
accesibles, manteniendo identificadores, URLs, valores de formularios, nombres de
marca y tokens técnicos. Los textos incrustados en imágenes y los mensajes ya
escritos por visitantes o por el asistente conservan su contenido original.

Los titulares con SplitText llevan una clave dependiente de su texto traducido:
React sustituye el titular completo al cambiar el idioma para evitar actualizar
nodos de texto que la animación ha reemplazado. El resto de la página conserva
su estado, incluidos los borradores del chat y los filtros de los demostradores.

Verificación: `npm run test:i18n`, `npm run test:chat`, `npm run lint` y
`npm run build`. Comprobar también ambos idiomas en móvil y escritorio, el cambio
con animaciones activas y con movimiento reducido, la navegación entre proyectos,
los filtros y la persistencia al recargar.
